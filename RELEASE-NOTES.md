# Holy Light × Eclipse 0.9.5 — Rehard

This release brings the HUD updates and fixes since 0.8.3 into one packaged download.

- Integrated boss timeline and clearer run clock / kill / gold / chest-price layout; uncertain pre-run timings are hidden.
- Separate boss HP area and live elite HP / respawn information in the left guardian list.
- Mirrored target, aligned aura rows, compact co-op frames and a matching minimap skin.
- Draggable, resizable and paginated RUN/BOSS/HEAL combat meter; narrower chat.
- Optional supported outgoing damage text and effective received-healing feedback.
- Boss-loot hover panels for the current class, with a dated 65-boss/nine-class reference. Recorded acquisitions and manual marks remain distinct from unknown collection state.
- New unaltered gameplay screenshots and a separately labelled AI-edited English interface guide in the README.

Install the attached HolyLightEclipse-0.9.5.zip, not GitHub's source archive. Replace the previous addon folder with the game closed; saved settings can remain.

Validation: local file/ZIP/XML/texture checks and restricted Lua 5.1/mock regression tests passed. Player-supplied screenshots show current desktop use; the exact client build was not recorded. This is not a complete every-class/platform certification. Full historical collection import, general all-enemy threat data and browser compatibility are not verified.
